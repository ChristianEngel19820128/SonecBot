## Künftige Pflege

- HANDOFF beim Übergang ersetzen bzw. aktualisieren; keinen Archiv-Snapshot für jeden Chat anlegen.
- Nur bei größeren Konsolidierungen oder abgeschlossenen Meilensteinen einen nachvollziehbaren Snapshot behalten. Laufende Einzeländerungen sind bereits über Git erhalten.
- Archive gezielt für eine konkrete historische Frage lesen. Offene Aufgaben bleiben in der aktiven Roadmap/TODO sichtbar; Archivierung entscheidet nicht über ihre Erledigung.
- Archivierte Dokumente sind keine aktuellen Arbeitsanweisungen.
