# SonecBot
Game written in App Game Kit Studio

Jump, Run, Fly & Shoot anything

This is a remake of a game I codet with BlitzMax in my early years.

The ingame control works only with Joypad.

## Branches

This repository has two branches:

- **[main](https://github.com/ChristianEngel19820128/SonecBot/tree/main)** — reference branch. It is not necessarily the latest development version or a published release.
- **[develop](https://github.com/ChristianEngel19820128/SonecBot/tree/develop)** — active development branch with current features, experiments, and fixes. Work here may be unfinished or untested.

For the latest development progress, see `develop`. Stable milestones can be brought to `main` after testing.
